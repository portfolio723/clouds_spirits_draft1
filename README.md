# Brand Compass

Clouds & Spirits — Brand Draft 01 Review Web App PRD

1.  Product Overview

Create a lightweight client-facing web application where the owner can review and compare the first branding direction for Clouds & Spirits without receiving a traditional PDF/document.

The application should feel like a combination of:

Notion

Apple/iOS

Premium design presentation

Simple brand review workspace

The purpose is not to make the owner learn a new tool. The owner should open the link and immediately understand:

“This is Draft 01 of my brand. I can look through the colors, typography and logo options, compare them, and give feedback.”

The experience should feel:

Clean → Calm → Premium → Easy → Visual → Review-focused

Not:

Corporate → Dashboard-heavy → AI-looking → Complicated → Presentation-heavy

The key UX decision is to make the owner feel like they're reviewing a beautifully designed brand, not filling out another form or operating a software dashboard.

The design team gets the complexity in the background through Supabase/admin functionality; the owner gets an intentionally quiet, visual, Apple/Notion-like review experience.
